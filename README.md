# unity_vr_lokomocja

Projekt generowany maszynowo za pomocą Claude Code i modelu Opus 5.5.

Tor przeszkód VR dla Meta Quest 3S w Unity 6.3 LTS (6000.3.24f1) do porównywania sposobów lokomocji (teleport, ruch płynny, obrót skokowy i płynny) i technik komfortu (winieta, mrugnięcie, dash, tryb siedzący). Sterowanie tylko kontrolerami Touch (`OVRInput`), grafika z prymitywów Unity, tablica wyników z oceną komfortu.

Szybki start: otwórz projekt, a potem **VR Lokomocja › 0. Szybki start**. Uruchamianie: **VR Lokomocja › 3. Build And Run (USB)** albo **4. Patch And Run**.

Instrukcja konfiguracji, Build & Run przez USB, optymalizacji, obsługi w goglach i opis działania: [INSTRUKCJA.md](INSTRUKCJA.md)
